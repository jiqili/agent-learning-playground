通过 DuckDuckGo 搜索网页。返回标题、URL 和内容：最多对排名前三的结果提取网页正文（最多 5,000 个字符）；其他结果或抓取失败的页面保留搜索摘要。
选择 `category`：
- text（默认）：事实、操作指南、文档、产品、人物/公司，以及实时数据页面（天气、股价、汇率、日程、比分）。不确定时使用 text。
- news：仅当用户询问已经发生的事情（事件、公告、事故、近期进展）时使用。天气等实时数据不要使用 news。
将 `query` 写成用户所用语言的普通关键词。只有日期确实重要时，才将“今天”等相对日期替换为具体日期；不要额外添加年份或“最新”等词。
只有在结果必须是近期发布时才设置 `timelimit`（news 默认使用 'w'）。若结果不相关，请更改类别或关键词，不要只换一种说法重复同一查询。
